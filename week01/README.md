## 실행 방법
 
<!-- 이 레포를 처음 clone 한 사람이 그대로 따라 하면 서버가 뜨도록 순서대로 적으세요. -->Node.js 24 LTS와 Git이 필요합니다.

1. 이 저장소의 Code → HTTPS 주소를 복사합니다.
2. 터미널에서 다음 명령으로 저장소를 내려받습니다.
   `복사한_주소` 부분은 실제 HTTPS 주소로 바꿉니다.

```bash
git clone 복사한_주소
cd KERT-Backend-Study
cd week01
npm install
```

3. 서버를 실행합니다.

```bash
npm start
```

개발 중 파일 저장 시 자동 재시작을 사용하려면 다음 명령으로 실행합니다.

```bash
npm run dev
```

두 실행 명령은 동시에 사용하지 않습니다.

4. 브라우저에서 http://localhost:3000 에 접속합니다.
5. 서버를 종료하려면 터미널에서 Ctrl + C를 누릅니다.
 
## 구현한 라우트
 
<!-- 만든 라우트와 각각 무엇을 보여주는지 적으세요. -->
| 경로 | 기능 |
|---|---|
| `/` | 홈 화면과 각 화면으로 이동하는 링크 |
| `/photo` | public/photo.jpg 사진 표시 |
| `/time` | 요청을 처리한 시각을 한국 시간으로 표시 |
| `/posts` | renderPostList 결과를 이용한 게시글 목록 |
| `/about` | 자기소개 |
| 그 외 경로 | 404 상태 코드와 안내 페이지 |

## (도전) /time 이 새로고침할 때마다 바뀌는 이유
 
<!-- (선택) 2~3줄로 적어보세요. -->새로고침하면 브라우저가 서버의 /time 경로로 새로운 요청을 보냅니다.
서버는 요청 처리 함수 안에서 new Date()를 실행해 현재 시각을 새로 구합니다.
따라서 새로고침할 때마다 새로 계산한 시각을 응답받습니다.
